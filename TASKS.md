# Tasks

Agent-readable task register. Conventions:

- Each task names an **assignee** (a person). Their agent may execute the
  agent-able parts and must surface the parts that need the human.
- Agents working from this file may **read the whole repository**;
  submissions come back through the channel named in the task or as a
  branch/PR — never direct pushes to the main branch (see `AGENTS.md`
  multi-agent rules; the integrator merges).
- Status: `open` → `in_progress` → `delivered` (assignee) → `done`
  (integrated). Update this file in the same change that delivers the work.
- Context for any task: `STATUS.md` (current state), `SME-REVIEW.md`
  (open domain questions), `DECISIONS.md` (decisions of record).
