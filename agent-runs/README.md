# Agent Runs

Use this directory for meaningful agent runs that affected code, architecture, process, or direction.

Do not log every casual chat. New humans need the decision trail and useful context, not every token.

Suggested run folder:

```text
agent-runs/YYYY-MM-DD-short-task/
  manifest.yaml
  planner-prompt.md
  planner-output.md
  implementer-summary.md
  test-evidence.md
  final.diff
  judge-output.md
  final-summary.md
```

Never store secrets, private customer data, or unnecessary sensitive prompt context.
