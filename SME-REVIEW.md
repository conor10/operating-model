# Domain Question Register

Open questions that require a domain expert's input. This file is the single
place such questions live so they cannot get lost in run records. Rules:

- **Any agent or human who surfaces a domain question they cannot resolve adds
  an entry here** (reviews, disagreement logs, error-analysis passes) rather
  than deciding silently.
- Every entry records the **interim default the project uses meanwhile** —
  nothing in this file blocks day-to-day work.
- Entries resolve only with the expert; resolutions that change data, labels,
  or semantics are applied via the normal review flow and, where they alter
  contracts, a `DECISIONS.md` entry. Resolved entries move to the bottom with
  their resolution — never deleted.
- When expert sign-off gates a milestone, this register is the session agenda.
